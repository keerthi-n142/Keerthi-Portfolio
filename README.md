# Keerthi N - Portfolio
    npm install
    npm run dev
## Add your files to `public/`
- `profile.jpg` : your photo (square works best)
- `resume.pdf`  : your resume
## Edit content
- `src/data/profile.js` : name, college, links, contact details
- `src/data/projects.js`, `skills.js`, `education.js`
- Contact form: set `sendMessage` in `src/components/sections/Contact.jsx` to connect an email service
